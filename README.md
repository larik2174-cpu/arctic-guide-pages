# Lyngen Alps Ascent

Build a one-page website for an IFMGA-certified mountain guide based in Tromsø/Lyngen, Norway. Name: Jimmy Halvardsson. Focus: ski touring in the Lyngen Alps.

Structure top to bottom:

Sticky nav: name + links (Winter 26/27, Programs, About, Contact)

Hero: headline "Ski touring in the Lyngen Alps with a certified mountain guide", subline about IFMGA certification and Tromsø base, two buttons (See open weeks / Get in touch), fact chips: IFMGA certified, Based in Tromsø/Lyngen, EN/SE/NO spoken

Winter 26/27 season section: interactive grid of weeks from December to April. Each week is a small card with dates and status: Open (orange), Limited (blue), Booked (gray, crossed out). Clicking a week shows a detail panel: program name, price, spots left, short note. Use placeholder weeks for now.

Programs: 3 cards (Ski Touring Week — price placeholder, Avalanche Course — price placeholder, Private Guiding — price per day placeholder), each with short description

About: photo placeholder left, text right, credentials list (IFMGA certification year, avalanche training, medical, seasons guided)

Contact: simple inquiry form (name, dates, group size, message) + email link

Footer: name, IFMGA Mountain Guide, Tromsø, Norway

Design: snow-white background #F6F7F5, dark slate text #1E2833, arctic fjord blue #2C5F80 for structure, one warm accent #E8611C only for "Open" statuses and main buttons. Fonts: Schibsted Grotesk for headings, Source Serif 4 for body. Clean, calm, professional — no stock-photo look, no generic gradients. Desktop and mobile.
